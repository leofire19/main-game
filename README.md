# MAIN · Asli atau AI? (Real or AI?)

**▶ Play now: https://leofire19.github.io/main-game/** (best on a phone)

MAIN is a 2-minute mobile web game that trains people to spot AI-generated
content and hoaxes — one swipe at a time. Built for the **UNESCO Youth
Hackathon 2026**.

## How it works

- Swipe **left** if you think a card is AI-made or a hoax, **right** if it's real.
- Cards include chain messages, headlines, and photo rounds (AI vs. real photographs).
- Every answer ends with a 10-second teachable moment: *why*, plus a concrete
  media-and-information-literacy habit (reverse image search, lateral reading,
  check the official source…).
- **Family Mode** enlarges text and prompts players to discuss before answering —
  designed for playing with parents and grandparents.
- Fully bilingual: auto-detects Indonesian / English, manual toggle included.
- Finish with a detection score and challenge your family over WhatsApp.

## Tech

One `index.html`, zero build steps, zero backend, zero tracking. Hoax items are
adapted from hoax archetypes already publicly debunked by Indonesian
fact-checkers; no live AI runs inside the game.

Run locally: open `index.html`, or `python -m http.server` and visit
`http://localhost:8000`.
